# 기준 특징 명세

이 명세는 수업용 Logistic Regression 기준 모델의 고정 특징을 정의합니다. EDA와 BVP의 생리적 구성 성분이나 박동 변이를 추정하는 방법은 포함하지 않습니다. 기존 논문의 특징을 그대로 재현한 설정도 아닙니다.

## 입력과 열 순서

구간 길이는 60초입니다. EDA는 4 Hz의 240개, BVP는 64 Hz의 3,840개 표본을 사용하며 두 신호의 시작·종료 시각은 동일합니다. 신호 자체의 원래 단위를 유지하고, 데이터 전체나 평가 참가자로부터 정규화 계수를 추정하지 않습니다.

열 순서는 `mean`, `std`, `min`, `max`, `median`, `iqr`, `slope`입니다. 각 열에는 신호 접두어를 붙입니다.

```text
eda_mean, eda_std, eda_min, eda_max, eda_median, eda_iqr, eda_slope
bvp_mean, bvp_std, bvp_min, bvp_max, bvp_median, bvp_iqr, bvp_slope
```

EDA 모델은 첫 7개, BVP 모델은 뒤 7개, 특징 융합 모델은 위 순서의 14개를 입력으로 받습니다. 참가자·구간·시각·원래 조건·정답은 이 목록에 포함되지 않습니다.

## 계산식

유효한 신호를 \(x_0,\ldots,x_{n-1}\), 표본 주파수를 \(f_s\), 시각을 \(t_i=i/f_s\)로 둡니다.

| 특징 | 정의 | 단위 |
|---|---|---|
| `mean` | \(\bar{x}=\frac1n\sum_i x_i\) | 원신호 단위 |
| `std` | \(\sqrt{\frac1n\sum_i(x_i-\bar{x})^2}\), `ddof=0` | 원신호 단위 |
| `min` | \(\min_i x_i\) | 원신호 단위 |
| `max` | \(\max_i x_i\) | 원신호 단위 |
| `median` | 선형 보간 방식의 50백분위수 | 원신호 단위 |
| `iqr` | 선형 보간 방식의 75백분위수−25백분위수 | 원신호 단위 |
| `slope` | \(\frac{\sum_i(t_i-\bar{t})(x_i-\bar{x})}{\sum_i(t_i-\bar{t})^2}\) | 원신호 단위/초 |

백분위수는 NumPy의 `method="linear"` 정의를 사용합니다. `slope`는 표본 인덱스당 변화량이 아니라 **초당 변화량**입니다. 따라서 같은 시간 기울기를 가진 4 Hz/64 Hz 신호의 기울기가 다르게 계산되지 않습니다.

## 결측·실패 규칙

- 입력 표본이 2개 미만이거나 표본에 NaN·양/음의 무한값이 하나라도 있으면, 해당 신호의 7개 특징을 모두 NaN으로 반환합니다. 나머지 유한값만 골라 서로 다른 시간 구간으로 계산하지 않습니다.
- 유한한 입력이어도 산술 오버플로 등으로 결과 중 하나가 비유한 값이 되면 해당 신호의 7개 특징을 모두 NaN으로 반환합니다.
- 유한한 상수 신호는 계산 가능한 입력입니다. 표준편차·IQR·기울기는 0이며, 이를 이유로 구간을 삭제하지 않습니다.
- 이 실패 정책은 특징 계산의 유효성 규칙이며, 센서 품질이나 움직임 잡음 탐지 기준이 아닙니다.
- 한 신호의 특징이 결측이어도 EDA·BVP·두 융합 모델은 동일한 구간을 평가합니다. 특정 모델에서만 행을 삭제하지 않습니다.

각 외부 학습 fold에서 열별 중앙값을 구해 학습·평가 특징에 적용합니다. 학습 자료에서 한 열 전체가 결측이면 해당 열의 대체값은 0으로 고정하고 열을 유지합니다. 이후 스케일러도 그 학습 자료에서만 맞춥니다. Advanced Model의 내부 검증에서는 이 과정을 **내부 학습 fold마다** 다시 수행해야 합니다.

## 해석 범위

EDA의 평균·변동과 BVP 파형의 통계적 특성을 요약하는 단순한 기준 표현입니다. BVP 평균이나 표준편차를 심박수·HRV로, EDA 기울기를 스트레스의 인과적 지표로 부르지 않습니다. 박동 검출, HRV, EDA 분해, 주파수 특징 등은 학생이 근거와 실패 처리 규칙을 추가하여 연구할 수 있는 확장입니다.
