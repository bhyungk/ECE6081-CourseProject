# 기준 특징 명세

## 입력

- 구간: 동일 시간대의 60초
- EDA: 4 Hz, 240개 표본 / BVP: 64 Hz, 3,840개 표본
- 열 순서: `mean`, `std`, `min`, `max`, `median`, `iqr`, `slope`
- 열 접두어: `eda_`, `bvp_`
- 입력 차원: EDA 7 / BVP 7 / 특징 융합 14(EDA → BVP 순서)
- 모델 입력 제외: 참가자·구간 ID, 시각, 원래 조건, 정답

## 계산

- 표기: 표본 $x_i$, 표본 수 $n$, 표본 주파수 $f_s$, 시각 $t_i=i/f_s$
- `mean`: $\bar{x}=\frac{1}{n}\sum_i x_i$
- `std`: $\sqrt{\frac{1}{n}\sum_i(x_i-\bar{x})^2}$, `ddof=0`
- `min` / `max`: 최솟값 / 최댓값
- `median`: 50백분위수
- `iqr`: 75백분위수 − 25백분위수
- 백분위수 보간: NumPy `method="linear"`
- `slope`: $\frac{\sum_i(t_i-\bar{t})(x_i-\bar{x})}{\sum_i(t_i-\bar{t})^2}$, 원신호 단위/초
- 나머지 특징 단위: 원신호 단위

## 결측·전처리

- 표본 2개 미만, 비유한 입력, 계산 결과 오버플로: 해당 신호의 7개 특징 모두 NaN
- 유한한 상수 신호: 표준편차·IQR·기울기 0, 구간 유지
- 결측 특징: 학습 자료의 열별 중앙값으로 대체
- 학습 열 전체 결측: 0으로 대체, 입력 열 유지
- 정규화: 학습 자료에만 StandardScaler 학습
- 내부 검증: 내부 학습 fold마다 대체값·스케일러 재학습
- 평가 구간: 특징 결측 여부와 관계없이 네 조건에서 동일하게 유지
