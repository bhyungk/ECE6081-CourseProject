# 배포 전 검증 기록

## 실제 데이터

- 검증일: 2026-11-03
- 대상: WESAD 15명(S2 ~ S11, S13 ~ S17)
- 입력: 손목 EDA 4 Hz / BVP 64 Hz / 라벨 700 Hz
- 구간: 기록 시작점 기준 60초 비중첩, 원래 조건 검사 후 이진 변환
- 포함 구간: 513개(Baseline 282 / Stress 152 / Amusement 79)
- 평가: 15명 LOSO, EDA·BVP·특징 융합·동일 가중치 예측 융합
- 출력: 구간별 예측 2,052행, 참가자별 점수 60행
- [기준 성능](../results/baseline/summary.csv): 참가자별 Macro-F1 평균·표본 표준편차

## 배포 전 검수

- 테스트: 44개 통과, 구간·특징·학습 전처리·참가자 분할·결과 저장·경로 비노출 검증
- 결과 검증: 파일 해시·추출 기록·동일 구간·학습 통계·확률 평균·지표 재계산 통과
- 설명 노트북: 13셀 실행 완료, 코드 셀 오류 없음
- 경로 보호: 노트북 출력·메타데이터에서 개인 절대 경로 제외, 실행 명령은 경로 대체 표기 사용
- 별도 새 환경: 고정 버전 56개 설치·의존성 검사·저장 특징 재평가 통과
- 환경 간 재현: 특징·manifest·예측·점수·요약·융합 차이·조건 오류·오류 중복·전처리 CSV 9개 바이트 일치
